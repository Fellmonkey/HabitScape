> **Жизнь не по расписанию. Привычки — тоже.**

HabitScape — это **мобильный трекер привычек с умными частотами** и **дневник
памяти** в одном приложении. Без серверов.

**Трекер, который подстраивается под реальную жизнь.** Большинство трекеров
требуют делать одно и то же каждый день. HabitScape устроен иначе: настрой
привычку ежедневно, по будням, N раз в неделю, раз в N дней или по собственному
циклу. Отметка — в один тап, «выполнить всё» — для целой группы. Пропустил
день? Просто пропустил: ничего не ломается, ничего не сбрасывается. Привычки
подстраиваются под тебя, а не наоборот.

**И дневник, который сохраняет твои дни.** Каждый вечер — трёхминутный ритуал:
одна строка о том, что запомнилось, и цвет настроения (🟢 хорошо / 🟡 так себе /
🔴 плохо). **«Разворот месяца»** — цифровой аналог бумажного разворота — показывает
весь месяц сеткой дней, окрашенной в цвет настроения, с отметками привычек,
строками моментов и целями месяца. Листай месяцы свайпом — и скролль свою жизнь.

Никаких серверов. Никаких аккаунтов. Никаких подписок. Твои данные живут
на твоём устройстве.

## ✨ Возможности

* 🔄 **Умные частоты** — ежедневно, по будням, N раз в неделю, раз в N дней,
  собственные циклы. Для сменной работы, занятых недель и нерегулярной жизни.
* ⚡ **Быстро в использовании** — отметка в один тап, «выполнить всё» в группе,
  свайп-меню для пропуска и удаления. Утром и вечером — по пять секунд.
  Работает офлайн.
* 🗓️ **Разворот месяца** — вся история на одном экране: ячейки дней в цвете
  настроения, отметки привычек, лента моментов и цели месяца. Свайп или
  стрелки — между месяцами; тап по дню — редактирование.
* 🕰️ **Момент дня** — одна строка о самом запоминающемся, цвет настроения
  и оценка «как использовал время» (1–5). Память, а не метрики.
* 📊 **Статистика** — тепловая карта года в стиле GitHub, тренд недель,
  корреляция «настроение ↔ выполнение» и ритм недели.
* 🎯 **Фокус и цели месяца** — отмечай 1–5 главных привычек и ставь цели
  прямо на развороте.
* 🔒 **Локально и без серверов** — все данные на устройстве, без аккаунтов.
  Резервная копия — обычный JSON-файл.
* 🌐 **Android + Web PWA** — установи из браузера, нативная сборка для Android.
* 🎨 **Маленькие приятности** — системная/светлая/тёмная тема, вибрация,
  одноразовые подсказки, русский интерфейс.
